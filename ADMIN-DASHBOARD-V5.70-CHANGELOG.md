# InternsForge Admin Dashboard V5.70

## Corporate header and profile
- Moved administrator identity/actions to the far-right side of the top header.
- Added responsive admin profile menu with Reset Password and Sign Out.
- Kept Navigation in the hero/header action zone.

## Compact dashboard
- Kept only the dashboard overview visible by default.
- Hidden operational modules remain available through Navigation workspaces.
- Standardized spacing and card proportions for a more spacious corporate layout.

## Workspace popups
- Centered workspaces with a controlled viewport height.
- Background page scrolling is locked while a workspace is open.
- Only the workspace content area scrolls vertically.
- Added smoother open/close transitions and stable scrollbar gutters.
- Preserved the user's page scroll position.
- Switching directly between workspaces no longer jumps to the top of the page.
- Desktop/tablet/mobile sizing is tuned independently.

## Navigation coverage
- Added Domain Insights, Audience Insights, and College Insights to the Applications cluster.
- Existing Live Visitors, Applications, Funnel, Activity, Referrals, Settings, Reset Password and Sign Out controls preserved.

## Compatibility
- Existing Firebase, live visitor monitoring, application manager, referral analytics, notifications, password reset and no-Blaze architecture preserved.
- No Firebase rules changes are required for V5.70.
