INTERNSFORGE CALL STATUS STANDARDIZATION

Canonical Call Status list:
1. Not Contacted
2. New
3. Connected
4. Callback
5. Details Shared
6. Follow-up
7. Interested
8. Not Interested
9. Not Picking
10. Paid / Pre-Reg
11. Enrolled
12. RNR
13. Invalid Number

Legacy mappings:
Called -> Connected
Call Back -> Callback
Selected -> Paid / Pre-Reg
Joined -> Enrolled
Not Reachable -> Not Picking

CENTRAL APPS SCRIPT
- Code.gs now uses the master spreadsheet ID explicitly.
- Counselor onEdit sync continues through the central script.
- Call Status data validation is applied to managed sheets.
- Run standardizeAllCallStatuses() once from the central Apps Script editor if existing rows still contain legacy status names.

APPLICATION MANAGEMENT DASHBOARD
- admin.html contains the same canonical status options in the filter and application modal.
- admin.js normalizes legacy Firebase statuses for display/filtering and updates metrics to Paid / Pre-Reg and Enrolled.
- dashboard.css includes styling for the canonical statuses.

IMPORTANT
The ZIP cannot change a Google Spreadsheet that is already deployed outside this package until the updated Code.gs is copied into the central Apps Script project (if you want the validation/migration functions there). Your Firebase and Google Sheets sync configuration remains in Script Properties.
