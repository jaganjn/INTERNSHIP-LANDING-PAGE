INTERNSFORGE — ACADEMIC COUNSELOR LEAD ASSIGNMENT

WHAT THIS VERSION DOES
1. Application Management has a direct Assign To counselor dropdown on every lead.
2. Select multiple leads and use Assign Selected for bulk assignment.
3. Add Counselor lets you add counselor names without editing code.
4. Each counselor automatically gets a DEDICATED Google Spreadsheet file.
5. Each counselor spreadsheet contains a lead sheet named <Counselor Name>'s Leads.
6. The master Sheet1 remains the central source of truth.
7. Editing CRM fields in a counselor sheet syncs back to the central Sheet1 and Firebase through an installable onEdit trigger.
8. The central Apps Script uses the master Spreadsheet ID explicitly, so counselor triggers always read the master Counselors registry.
9. The Call Status dropdown is standardized across the master sheet and managed counselor sheets.

ONE-TIME APPS SCRIPT SETUP
- Replace the central project's Code.gs with the included Code.gs if you are updating the Apps Script from this package.
- Keep FIREBASE_SERVICE_ACCOUNT_JSON in Script Properties.
- Keep the existing counselor installable triggers.
- If a counselor connection needs to be rebuilt, use testCounselorConnection() from the central project.
- Run standardizeAllCallStatuses() once if existing rows still contain old status names.
- If using the Web App endpoint, update the existing Web App deployment to a new version while keeping the same deployment URL.

IMPORTANT
The dashboard package does not by itself modify a Google Spreadsheet that is already deployed in your account. The included Code.gs contains the central-sheet/counselor synchronization and dropdown-validation logic for the Apps Script project.
