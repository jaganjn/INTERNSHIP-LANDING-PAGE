GOOGLE SHEETS RECOVERY / DEPLOYMENT

1. Open the Apps Script project attached to the response spreadsheet.
2. Replace the old Code.gs contents with:
   GoogleAppsScript-APPLICATION-RECEIVER-FIXED.js
3. Save.
4. Deploy > Manage deployments.
5. Edit the Web app deployment, or create a new Web app deployment.
6. Execute as: Me.
7. Who has access: Anyone.
8. Deploy and authorize if Google asks.
9. Keep the resulting /exec URL in index.html as SHEET_ENDPOINT.

IMPORTANT:
- Do not delete existing spreadsheet rows.
- The new receiver adds missing columns automatically.
- Application ID is used as an idempotency key, so retries/Admin sync do not duplicate rows.
- The current landing page writes applications to Firebase first, then sends them to Sheets.
- The Admin Panel now has "Sync to Google Sheets". Use it to recover all applications currently stored in Firebase, including today's applications that did not reach Sheets.
- If the Apps Script deployment URL changes, update SHEET_ENDPOINT in index.html and admin.js.
