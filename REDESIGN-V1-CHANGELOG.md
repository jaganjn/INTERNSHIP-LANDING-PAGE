# InternsForge Website Conversion Redesign V1

Frontend-only redesign. Backend/Firebase/Google Apps Script files were not modified.

## Goals
- Make the landing page simpler and more conversion-focused.
- Reduce visual density and improve hierarchy, spacing, typography and responsive behavior.
- Keep the application flow and all existing field IDs/JS hooks intact.
- Make the application experience feel like a focused workspace rather than a long page.

## Key changes
- Reworked hero headline, supporting copy and primary CTA.
- Stronger trust/proof row and programme facts.
- Refined dark career-readiness visual panel.
- Cleaner application section hierarchy and copy.
- Preserved 3-step application wizard, draft saving, validation and Firebase hooks.
- Refined application modal sizing and internal scrolling.
- Improved domain explorer presentation and card hover/focus behavior.
- Improved student journey section and responsive horizontal scroller.
- Refined section spacing, card borders, shadows and typography.
- Added a compact domain-explorer reassurance CTA near the final conversion area.
- Added reduced-motion support.
- Mobile layout uses larger tap targets, one-column form controls and full-width primary actions.
