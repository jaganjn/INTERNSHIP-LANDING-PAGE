# InternsForge V10 — Logo Visibility

## Root cause
The previous SVG used a dark navy fill for the "Interns" wordmark on a dark navbar, making it low-contrast. The logo was also rendered at a small effective width.

## Fix
- Changed the "Interns" SVG wordmark to a light, high-contrast color.
- Lightened the tagline.
- Increased logo width to 190px desktop / 165px tablet / 145px mobile / 128px small phone.
- Removed the duplicate HTML brand text next to the SVG.
- Preserved the teal "Forge" identity and existing logo shape.
