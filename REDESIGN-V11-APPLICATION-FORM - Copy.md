# InternsForge V11 — Application Form Redesign

## Trigger
The redesign applies to the existing application modal opened by the main Start Your Journey / application CTA.

## New visual structure
- Dark, branded left journey rail on desktop.
- Clean white application workspace on the right.
- Dedicated four-stage journey: Personal → Academic → Profile → Review.
- Compact status/progress header.
- Smaller current-step banner.
- Cleaner form fields with stronger focus states.
- Modern action bar with clearer primary/secondary actions.
- Redesigned modal close control.
- Mobile becomes a dedicated single-column application experience with the rail removed.
- Modal opening animation and responsive behavior.

## Functionality
No field IDs, form IDs, validation names, or submission hooks were removed.
