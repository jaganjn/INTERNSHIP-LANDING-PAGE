# InternsForge V13 — Compact Application Modal

## What changed
The application is now a true product-style modal:
- No large blank/unused space above the application header.
- Modal is centered in the viewport.
- Application content starts immediately from the top.
- Header, hero and step progress stay fixed within the modal.
- Only the form content scrolls.
- Close control stays in the upper-right.
- Desktop, tablet and mobile use responsive modal dimensions.
- The existing application logic and form IDs remain intact.

## Removed from active layout
No left application rail and no reserved side column are used.
