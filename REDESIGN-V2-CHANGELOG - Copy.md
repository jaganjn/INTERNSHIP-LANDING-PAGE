# InternsForge Frontend Redesign V2

## What changed
- Reworked the landing-page hero into a dark cinematic "Forge Your Future" entrance.
- Added an interactive Career Path Explorer with four role directions.
- Added a Learn → Build → Show "Proof Stack" section.
- Updated page title and meta description for the new positioning.
- Refreshed top navigation language and CTA.
- Rethemed public sections with a modern dark/light product-style system.
- Improved responsive behaviour for hero, role explorer, proof stack and final CTA.
- Kept the existing application form, Firebase hooks, admin files, domain explorer and supporting logic in place.
- Added a small isolated interaction script for the new Career Path Explorer.

## Important
The existing Firebase/application/backend files were not removed. The redesign is intentionally layered into the public front-end so existing workflows remain available.
