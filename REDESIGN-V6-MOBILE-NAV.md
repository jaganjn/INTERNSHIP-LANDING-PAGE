# InternsForge V6 — Mobile Navigation Redesign

## Problem fixed
The previous mobile header reused desktop/hero navigation rules, leaving a large rounded bar with an awkward menu treatment.

## New mobile design
- Compact 60px-ish sticky header.
- InternsForge logo + brand lockup on the left.
- Clean hamburger control on the right.
- Full-width dark navigation drawer on phones.
- Links: Home, Career Paths, Domains, Process, FAQ.
- Dedicated Start Application button.
- Drawer closes after navigation.
- Separate tablet and small-phone breakpoints.
- Desktop navigation remains a horizontal nav with its own CTA.

## Layout
The header remains in document flow so it does not cover the hero.
